# CHANGES · 2026-10-05

## 同步设置改为「草稿 + 显式保存」

修复同步设置窗口"测试连接一通过就自动保存并替换旧配置"的问题。此前界面所有输入框
的 setter 直接写 `SyncSettings` 并立即落盘（每敲一个字写一次 settings.json），
"测试连接"又用界面当前值构造临时后端，等于测试即覆盖旧配置且无法回退。

**变更范围**

- `ViewModels/SyncSettingsViewModel.cs`：全部可编辑项改为草稿字段，仅标脏不落盘；
  新增「保存」命令（唯一写回 `Sync` 的入口）、`HasUnsavedChanges`/`SaveHintText`
  状态、密码凭据提示区分"已输入新密码（保存后生效）"
- `Views/SyncSettingsWindow.xaml`：按钮行新增主按钮「保存」，"测试连接"降为次要样式，
  下方新增保存提示行
- `Views/SyncSettingsWindow.xaml.cs`：拦截关闭时的未保存修改（确认后丢弃草稿），
  保存成功后清空两个密码框

**行为约定**

- 「测试连接」只读取草稿值探测连通性，不触碰已保存配置；成功提示中提醒需点「保存」
- 「立即同步」在有未保存修改时拒绝执行并提示先保存（只用已保存配置）
- 「保存」才写回 `SyncSettings`、落盘并通知 `SyncHost` 重建定时器；保存后记录日志
- 保存后凭据明文从草稿与密码框清除，密文已由 DPAPI 落盘

**验证**

- 主项目编译 0 警告 0 错误
- 测试套件 142 通过 / 0 失败（1 跳过为原有环境相关用例）

## 界面语义色切换为 Material Design 3 配色（浅色）

将 `Resources/StickyColors.xaml` 中 16 个 `Fluent.*` 语义画刷的取值替换为 Material Design 3
`schemes.light` 方案对应的角色色，色源为 Material Theme Builder 导出的 `temp/material-theme.json`
（seed `#0064B5`）。

**变更范围**

- 仅改动 `src/StickyNotes/Resources/StickyColors.xaml` 一个文件
- 画刷键名全部保持不变，98 处 `Fluent.*` 引用与全部 XAML 无需改动
- 便签内容色（7 组 `Sticky.*`）为正交维度，字节级未改动

**关键取值变化**

| 角色 | 旧值 | 新值 |
| --- | --- | --- |
| 主色 | `#0078D4` | `#3B608F` |
| 卡片底色 | `#FFFFFF` | `#F2F3FA`（surfaceContainerLow） |
| 弱描边 | `#1E000000` 半透明黑 | `#C3C6CF` 不透明（outlineVariant） |

**顺带修复**

- 原 `SubtleBorderBrush` / `ControlBorderBrush` 使用半透明黑，在深色背景下等同隐形。
  按 M3 规范改为不透明色，为后续深色主题铺路。

**关于 Wpf.Ui 控件的强调色（已核实，非缺陷）**

- 项目共使用 6 类 Wpf.Ui 控件、120 个实例：`ui:Button` 46、`ui:SymbolIcon` 39、
  `ui:TextBox` 14、`ui:FluentWindow` 10、`ui:ToggleSwitch` 6、`ui:TitleBar` 5；
  手写 `.cs` 中仅 6 处引用（Wpf.Ui 出现的其余位置均为 `obj/` 生成物）。
- 开关呈 `#005CA4`，此为 **Windows 系统个性化强调色**，非 Wpf.Ui 写死色，也非本项目主色。
  源码依据：`UiApplication.ApplySystemAccentColor` 默认为 `true`，启动时自动调用
  `ApplicationAccentColorManager.ApplySystemAccent()`，从 `UIColorType.Accent`
  读取系统强调色注入 `SystemAccentColor` 系列资源。因此该色随系统主题变化。
- 结论：切换主色需先决定产品取向 —— 保持跟随系统强调色（Windows 原生惯例，
  与 FluentWindow / TitleBar 的设计语言一致），或改为固定 `#3B608F` 以严格对齐 M3。
  此前"呈亮蓝色、与主色不协调"的描述不准确，现更正。

**遗留事项**

- 强调色是否固定为 M3 主色，待产品决策（见上节）。
- `CardDefaultBgBrush`（纯白）在无边框场景（如归档窗口空状态）与窗口底色对比仅 1.04，
  边界不可见，后续需补边框或改用 surfaceContainerLow。
- 本轮仅落地浅色。深色模式需先完成 82 处 `StaticResource` → `DynamicResource` 改造，
  否则切换主题不会生效。
