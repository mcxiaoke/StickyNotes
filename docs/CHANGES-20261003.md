## 2026-10-03 12:04 — 新增 PIN 锁定（防偷窥轻量保护）与列表闲时自动收起

### PIN 锁定

- 设置窗口新增「隐私保护」分组：启用/修改/清除 PIN，修改与清除均需先验证当前 PIN，防止他人绕过设置关锁。
- PIN 规则：4~20 位、内容不限，普通 PasswordBox 输入、Enter 确认；定位为防偷窥轻量保护，不做应用内找回（遮罩上有指引：退出应用后手动删除 settings.json 中 PinEnabled/PinSalt/PinHash 三个字段即可重置）。
- PIN 不存明文：PBKDF2-SHA256（2 万次迭代）+ 16 字节随机盐后写入 settings.json，验证采用恒定时间比较。
- 锁定呈现为窗口内不透明遮罩（新控件 PinLockOverlay，复用于列表与归档窗口），不引入独立解锁窗口与全局解锁状态；错误时抖动 + 红字提示。
- 锁定规则：列表窗口每次从不可见变为可见（应用启动、托盘/热键唤醒）都重新上锁；窗口保持打开期间不重复打扰。桌面贴纸不上锁。
- 归档窗口打开时：若主列表处于解锁可见状态则直接放行（视为刚验证过身份），否则同样上锁，避免绕过列表直取归档内容。

### 闲时自动收起

- 列表窗口（及归档窗口）持续不在前台达到设定分钟数后自动关闭/收起到托盘，下次打开需重新输 PIN（若已启用）。
- 设置项默认 10 分钟，可选 不启用/1/5/10/30 分钟；实现为 Deactivated/Activated + DispatcherTimer，不追踪键鼠输入。
