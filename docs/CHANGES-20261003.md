## 2026-10-03 14:26 (GMT+8) — 修复输入框方向键监听机制（PreviewKeyDown 穿透拦截）
- **核心问题定位**：WPF `TextBox` 在其内部控件处理程序中直接将 `Key.Down` / `Key.Up` 标记为 `e.Handled = true`（用于文本光标选择），导致冒泡的 `KeyDown` 事件被阻断吞噬，用户在输入框按方向键无法下移。

  1. 将 `SearchBox` 的按键事件从冒泡的 `KeyDown` 升级为隧道拦截的 `PreviewKeyDown="SearchBox_PreviewKeyDown"`，确保在 TextBox 内部消费前精准捕获方向键与回车；
  2. 无论是单按 **`↓` (Down)** 还是按 **`Ctrl+↓`**，均可无缝捕获并下移焦点至列表首项；
  3. 在 `FocusListBoxItem` 中增加 `listBox.Focus()`，确保焦点从输入框瞬间成功转移到列表容器；

  - 证明纯内存遍历与 .NET 8 AVX2 SIMD 向量化 `IndexOf` 具备极高的吞吐与响应能力，无需原先保守的 300ms 延迟。
- **体验优化**：
  - 将防抖延迟从 **300ms 锐减至 80ms**：刚好抵消键盘连击微抖动，手指敲下抬起的瞬间结果即刻呈现在屏幕上，达到“零感知延迟”的即输即现效果；

- **核心优化目标**：
  1. 解决原搜索仅支持单一连续子串，导致搜 `open router` 无法匹配到便签内 `openrouter` 或跨行多词的问题；

  2. **三行智能上下文提取**：围绕首个命中行精准提取前一行、当前命中行及后一行（首行/单行/末行不足三行时自适应显示实际行数），前部有未展示内容时自动添加 `...` 省略号；

- **核心问题定位**：
  1. `NotesListViewModel` 搜索即输即搜时，若用户清空搜索框（按 Backspace、Esc 或点击 Clear 按钮），原代码对 `_searchCts` 调用 `Cancel()` 与 `Dispose()` 后未将引用置空；

- **重点修复方案**：
  1. 引入原子安全的 `CancelCurrentSearch()`，通过 `Interlocked.Exchange(ref _searchCts, null)` 提取并安全释放旧搜索任务，杜绝悬空引用与多线程重复释放风险；
  2. 修复 `OnSearchTextChanged` 在清空时安全重置状态，后续任何新输入均可正常生成全新的 CTS 触发防抖搜索；
  3. 优化 UI 结果投递线程判断，增加取消令牌二次校验，并适配无 Dispatcher 消息泵的单元测试环境；

## 2026-10-03 12:04 — 新增 PIN 锁定（防偷窥轻量保护）与列表闲时自动收起

### PIN 锁定

- 设置窗口新增「隐私保护」分组：启用/修改/清除 PIN，修改与清除均需先验证当前 PIN，防止他人绕过设置关锁。
- PIN 规则：4~20 位、内容不限，普通 PasswordBox 输入、Enter 确认；定位为防偷窥轻量保护，不做应用内找回（遮罩上有指引：退出应用后手动删除 settings.json 中 PinEnabled/PinSalt/PinHash 三个字段即可重置）。
- PIN 不存明文：PBKDF2-SHA256（2 万次迭代）+ 16 字节随机盐后写入 settings.json，验证采用恒定时间比较。
- 锁定呈现为窗口内不透明遮罩（新控件 PinLockOverlay，复用于列表与归档窗口），不引入独立解锁窗口与全局解锁状态；错误时抖动 + 红字提示。
- 锁定规则：列表窗口每次从不可见变为可见（应用启动、托盘/热键唤醒）都重新上锁；窗口保持打开期间不重复打扰。桌面贴纸不上锁。
- 归档窗口打开时：若主列表处于解锁可见状态则直接放行（视为刚验证过身份），否则同样上锁，避免绕过列表直取归档内容。

### 闲时自动收起

- 列表窗口（及归档窗口）持续不在前台达到设定分钟数后自动关闭/收起到托盘，下次打开需重新输 PIN（若已启用）。
- 设置项默认 10 分钟，可选 不启用/1/5/10/30 分钟；实现为 Deactivated/Activated + DispatcherTimer，不追踪键鼠输入。
