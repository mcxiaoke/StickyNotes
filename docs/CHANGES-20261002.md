# 项目变更日志 (2026-10-02)

### [2026-10-02 11:30 (GMT+8)] 模块 0 · 数据可靠性与基础生命周期止血交付 (Phase 0 P0 缺陷清零)
- **P0-1 桌面布局退出与恢复修复**：在 `WindowManager` 与 `App` 中区分“用户主动关闭单张便签”与“应用/系统退出连带关闭”；退出时通过 `PersistActiveWindowsBoundsOnExit` 同步持久化物理坐标尺寸并保持 `IsOpen = true`，下次启动完美恢复桌面所有敞开贴纸；
- **P0-4 退出刷盘同步化、关机响应与死锁纠偏**：`App.OnExit` 改回同步等待，挂接 `SystemEvents.SessionEnding` 监听系统注销与关机；`AutoSaveCoordinator` 新增 `FlushAllDirectToStorage` 直达底层仓储落盘，彻底隔离 UI 消息总线，消除了 `Dispatcher.Invoke` 与 UI 线程阻塞的死锁隐患；
- **P0-5 基础设施日志与三层全局异常兜底**：实现轻量级按日滚动文件日志 `AppLog`（Release 构建正常生效）；挂接 `DispatcherUnhandledException`、`AppDomain.UnhandledException`、`TaskScheduler.UnobservedTaskException` 自动落盘并安全刷盘；全项目彻底清理 `Debug.WriteLine`；
- **P0-3 WAL 模式下事务一致性冷备份**：重构 `BackupService`，废除裸拷 `File.Copy`，改用 SQLite 原生 `VACUUM INTO` 语法生成物理一致性快照；采用 `.tmp` 临时文件原子替换；将每日备份移至后台线程异步执行，冷启动完全不阻塞主窗口呈现；
- **P0-2 导入备份冲突裁决与事务化**：重构 `ExportImportService`，导入备份时比对本地记录的 `UpdatedAt`，默认跳过较旧备份项防止新笔记被静默回滚；在 `INoteRepository` 中扩展 `SaveBatchAsync` 事务批量操作，导入失败整体回滚；
- **自动化测试扩充至 37 项**：全量测试 100% 通过（37/37 Passed），新增 `LifecycleAndReliabilityTests` 完整覆盖窗口退出恢复、导入冲突比对、VACUUM 冷备份还原、防死锁刷盘与日志验证。
